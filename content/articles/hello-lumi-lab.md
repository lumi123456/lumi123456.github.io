# 欢迎来到 lumi 的成长实验室

学习不应该只是收藏资料，也应该留下可以检索、复用和分享的成果。

这个网站会持续整理以下学习路径：

## Python 基础

从语法、数据结构、函数到面向对象，记录可靠的基础知识与练习。

## Python 进阶

继续探索工程化、异步编程，以及 NumPy、Pandas 等数据处理工具。

## 机器学习与深度学习

从 Scikit-learn 的经典算法出发，继续学习 PyTorch、神经网络和模型训练。

## NLP

理解文本表示、Transformer、BERT，以及现代大语言模型的技术基础。

## 大模型提示词技术

整理提示词设计方法、常见框架、效果评估，以及真实任务中的调试经验。

## 低代码平台、RAG 与 Agent

使用 Coze、Dify 快速验证想法，继续学习检索增强生成、模型微调和 LangChain Agent。

## 后端与前端

补齐接口、数据库、部署和产品界面能力，最终完成可以真正使用的端到端应用。

> 网站与文章都在持续完善中。每一次更新，都会让知识地图更完整一点。
